# Dot Widgets Pro: Theme Studio plan

Status: Phases 1 and 2 built with starter art (Clay Red, Clay Blue); not yet tested on a phone. Created 2026-10-31.

Built differently from this plan:
- Starter art is generated by `store-listing/source/theme_art.cjs`, so Phase 0 is now an upgrade, not a blocker. Final art replaces files of the same name.
- Theme Studio is one Settings card (`ThemeStudioCard.kt`) instead of separate screens.
- All widgets fit the existing 2×2 and 4×2 sizes, so no new provider or manifest change was needed. Pills are drawn in a 4×2 slot.
- `tile_photo_frame`, `tile_pill_frame` and `accent_detail` are not needed until Phase 3.
- `ExampleRobolectricTest.kt` and `PhotoStore.kt` were not changed.

## 1. Goal

Add premium image-based themes (3D Clay, Plush, Glass, Neon), a control-centre widget set and
user photos inside themed tiles, while leaving the existing 223 widgets and their code as they are.

The look in the reference ads comes from generated images cut into tiles, with icons on top. We use
the same idea, but the time, battery, song title and toggle states on top are live.

## 2. The "no changes to existing files" rule

All new work goes into new files. Nothing existing is rewritten, restyled or moved.

Android still has to be told that the new code exists, so a very small number of existing files
need a one-line connection. Without these lines the feature cannot be reached. They are listed in
full here, and go in one small commit so they are easy to review or remove.

| Existing file | Change | Needed for | Phase |
|---|---|---|---|
| `widgets/base/WidgetRegistry.kt` | 1 line in `init`: register the theme widgets | New widgets appear in the app | 2 |
| `widgets/base/WidgetSpec.kt` | 1 enum line: `THEMES` category | A "Themes" filter on the Widgets tab | 2 |
| `ui/settings/SettingsScreen.kt` | 1 line: show `ThemeStudioCard` | Way in to Theme Studio | 1 |
| `widgets/base/WidgetTapTargets.kt` | About 1 line: delegate theme widget regions | Buttons inside theme tiles work (to confirm in Phase 2) | 2 |
| `data/photos/PhotoStore.kt` | 1 map entry per photo tile | Existing photo picker works for photo tiles | 3 |
| `ExampleRobolectricTest.kt` | Update the expected widget count | The catalogue test still passes | 2 |
| `app/build.gradle.kts` | Billing library, new version code | Subscription (Phase 5 only) | 5 |

Not changed: `DotMatrixRenderer`, `Skin.kt`, `RenderKit`, `WidgetRenderEngine`, the customize
screen, existing widgets, existing setups and Looks, database schema, widget providers.

**Trade-off of this rule:** the new styles apply only to the new theme widgets, not to the existing
223. Bringing Clay or Neon to all 223 would mean changing `Skin.kt` and `DotMatrixRenderer`, so it is
left as an optional later phase (Phase 6) and needs a separate decision.

No new permissions. No manifest change expected, because theme widgets reuse the existing providers
and tap actions.

## 3. New files

```

  ThemeRepository.kt      lists bundled packs, stores the chosen pack

  ThemeCanvas.kt          draws tile image + live icons, text and state on top
  ThemeWidgets.kt         the control-centre widget definitions

  ui/ThemeDetailScreen.kt pack preview and the widgets in it
  ui/MyThemeScreen.kt     user-made themes (Phase 4)

app/src/test/java/com/example/ThemePackTest.kt
```

## 4. Phases

Each phase ends with tests, a build, install on the phone and a push.

### Phase 0: Art for the first pack (you)
Create the Clay Red images from section 5 with an AI image tool or a designer.
**Done when:** all 12 images are in `docs/theme-art/clay-red/` and the tool's terms allow commercial use.

### Phase 1: Theme engine and Theme Studio
Load packs, draw tiles with live content, gallery in Settings, apply a pack's wallpaper.
**Done when:** Clay Red shows in the gallery with real previews, and memory stays within the widget limit.

### Phase 2: Control-centre widget set
| Widget | Size | Live content |
|---|---|---|
| Quick Toggles | 2×2 | Wi-Fi, Bluetooth, torch, Do Not Disturb state |
| Music | 2×2 | Song, artist, play controls |
| Focus Pill | 4×1 style pill | Focus timer |
| Greeting Pill | 4×1 style pill | Time-of-day message |
| Brightness and Volume Sliders | Tall | Level display; opens the system panel |
| Round Shortcuts | 1×1 style | Chosen app or system action |
| Clock and Date Tiles | 2×2, 4×2 | Time, date |
| Battery Tile | 2×2 | Level, charging |

To check first: the launcher's real minimum sizes for 1×1 and pill widgets, since the existing
providers are built for 2×2, 4×2 and 4×4. If pills need a new provider, that adds a manifest entry
and a provider XML, and this table's sizes change.

Android limits apply: Wi-Fi and Bluetooth buttons usually open a system panel rather than switching
directly, and changing brightness needs a special permission, so the slider opens the panel.
**Done when:** all widgets work on the phone in Clay Red, and every button does what it shows.

### Phase 3: Custom images
Users put their own photo into any theme tile: choose the tile, crop and zoom, darken for
readability. Uses the existing Android photo picker, so no storage permission. Images stay on the
phone. Large photos are scaled down; GIFs and videos are not supported.
**Done when:** a photo tile survives a reboot and an app update, and text on it stays readable.

### Phase 4: More packs and My Theme
Add Clay Blue, Plush Blue, Glass Blue and Neon Dark (art needed, section 5). Users save a pack plus
their photos as "My Theme". Accent colour can be taken from their wallpaper.
**Done when:** switching packs repaints all theme widgets in one tap.

### Phase 5: ₹149 monthly plan
Needs a merchant account first. Add Google Play Billing, a paywall, restore purchases and a clear
message when a subscription ends. Decide which packs are included. Update the "free" wording in the
README, privacy policy, Settings and welcome screen before this ships.
**Done when:** a test purchase, cancel and restore all work through Play's test accounts.

### Phase 6 (optional): Clay and Neon on all 223 widgets
Needs changes to `Skin.kt` and `DotMatrixRenderer`, so it breaks the no-changes rule. Only do this
if you approve it separately.

## 5. Art needed

Every pack needs these 12 images. Keep a master at the size shown; the app ships smaller WebP copies.

| File | Size (px) | Content |
|---|---|---|
| `wallpaper` | 1440×3200 | Full wallpaper matching the pack |
| `tile_square` | 1024×1024 | Empty rounded square |
| `tile_quad` | 1024×1024 | Square with four empty round wells |
| `tile_wide` | 1024×512 | Empty wide rounded tile |
| `tile_pill` | 1024×340 | Empty pill |
| `tile_tall` | 512×1024 | Empty tall capsule |
| `tile_tall_fill` | 512×1024 | Same capsule in the accent colour, for slider fill |
| `button_on` | 512×512 | Round button, accent colour |
| `button_off` | 512×512 | Round button, dark |
| `tile_photo_frame` | 1024×1024 | Frame with a clear centre (transparent PNG) |
| `tile_pill_frame` | 1024×340 | Pill frame with a clear centre (transparent PNG) |
| `accent_detail` | 512×512 | Small decoration (transparent PNG) |

Rules: no text, no icons, no logos, no characters, plain transparent or solid background around each
shape, and lighting from the top-left on every image.

Prompt for Clay Red (change the shape each time):

> Single empty [rounded square tile] for a phone widget, soft 3D clay material, glossy red rim,
> matte charcoal centre, smooth puffy edges, soft studio lighting from the top left, subtle shadow,
> centred, plain background, no text, no icons, no characters, high detail, 1:1

Swap the material for other packs:
- **Plush Blue:** soft plush fabric, short blue fur with cream accents.
- **Glass Blue:** clear frosted glass, thin bright rim, soft reflections.
- **Neon Dark:** dark panel, thin glowing blue and orange outline.

Devotional packs need original or licensed art, and must be respectful. Joker, Tom & Jerry and other
protected characters must not be bundled. Users may add their own images for personal use (Phase 3).

## 6. Risks

| Risk | Plan |
|---|---|
| App size grows | Target about 1.5 MB per pack with WebP; bundle 3–4 packs; download packs later |
| Widget memory limit | Size images to the existing budget per widget; test on the phone |
| Glass only suits its own wallpaper | Apply the wallpaper with the pack, and say so in the app |
| Launcher may not accept pill or 1×1 sizes | Test in Phase 2 before building those widgets |
| Copyright in generated art | Avoid character or brand names in prompts; check the tool's terms |
| Screenshot and listing claims | Update the store images only when a feature has shipped |
